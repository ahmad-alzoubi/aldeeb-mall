# 🛒 الديب مول (Aldeeb Mall) — المنظومة المتكاملة للهايبرماركت الإلكتروني

مشروع متكامل بنمط منصات كارفور العالمية (Carrefour)، يشمل:
1. **📱 تطبيق الهاتف الذكي والمتجر الإلكتروني (`aldeeb_mall_app`)**:
   - مبني بتقنية **Flutter Multiplatform** (يعمل على iOS، Android، و Web).
   - تصميم عربي فاخر (RTL-First) بالهوية البصرية لكارفور (أزرق ملكي مع أحمر جذاب).
   - تصفح الأقسام، العروض والصفقات الكبرى مع عداد تنازلي، سلة شراء ذكية مع شريط التوصيل المجاني، اختيار خانات التوصيل، كوبونات الخصم، ونظام مكافآت نقاط الولاء مع بطاقة رقمية بباركود للمسح في المول.
2. **💻 لوحة التحكم والإدارة المتطورة (`aldeeb_mall_admin`)**:
   - مبنية بتقنية **React 19 + TypeScript + Tailwind CSS + Lucide Icons**.
   - إدارة غرف العمليات والطلبات الفورية مع تنبيه صوتي عند وصول أي طلب جديد.
   - كتالوج المنتجات والمخزون، إضافة المنتجات وحساب الخصم والباركود فورياً.
   - مركز إدارة الكوبونات ونادي نقاط ولاء العملاء.
3. **⚡ البنية السحابية وقاعدة البيانات (`supabase/`)**:
   - ملفات SQL جاهزة ومفهرسة تشمل (الجداول، سياسات RLS المحمية، تريجرز نقاط الولاء الآلية، ودوال فحص الكوبونات).
   - كتالوج كامل يضم أكثر من 9 أقسام هايبرماركت رئيسية مع صور حقيقية عالية الجودة وأسعار وباركودات.

## 🚀 تشغيل النظام (How to Run)

### 1. تشغيل لوحة الإدارة (Admin Dashboard):
```bash
cd aldeeb_mall_admin
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

---

### 2. تشغيل تطبيق الهاتف أو متجر الويب (Flutter App):
```bash
cd aldeeb_mall_app

# للتشغيل كمتجر ويب على المتصفح:
flutter run -d chrome

# للتشغيل على محاكي الأندرويد أو الآيفون:
flutter run
```
